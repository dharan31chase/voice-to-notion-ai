🔀 How Data Flows Through the System

1

Voice → Notion (Primary)

Sony recorder → USB detect → Groq transcribe → GPT-4 analyze → Notion upload → Archive

~5-15 min batch processing
2

Git → Notion (Sync)

Commit with [ROADMAP-X] tag → Post-commit hook → Update Roadmap DB → Create Session entry

~2-5 sec per commit (blocking)
3

Claude Chat → Context (Session Start)

start_session() → Check learned profile → Suggest files → Load into context

~3-5 sec
4

Query → RAG Results (Search)

Search query → BM25 + Semantic → Hybrid merge → BGE rerank → Top 5 results

~500ms
