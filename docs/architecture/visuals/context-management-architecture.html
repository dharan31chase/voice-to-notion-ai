What's Wrong

  • No Visibility: User can't see which files are loaded
  • One-Time Only: Context set at start, can't adjust mid-session
  • Bad Suggestions: Generic heuristics often wrong, suggest useless files
  • No Learning: Same mistakes repeated, system never improves
  • Manual File Access: To add file, must navigate folders, copy exact path
  • Restart Spiral: Pivot topic → need different context → restart chat → lose 20 min of work → repeat

Key Technical Decisions

Decision 1: Mini-RAG vs Simple Search (Phase 3)

Question: Epic 2nd Brain corpus is ~50k tokens. Is that large enough to justify RAG overhead?

Options:

  • A: Simple ripgrep keyword search (fast, simple)
  • B: Mini-RAG with ChromaDB (semantic, more complex)

Recommendation: Start with ripgrep, monitor Phase 2 usage, upgrade to RAG if search quality insufficient

Rationale: Corpus might be too small. Can add RAG later if needed.

Decision 2: Usage Tracking Scope

What to track:

  • ✅ Files loaded at start (from suggestions)
  • ✅ Files added/removed mid-session (explicit signals)
  • ✅ Files referenced in responses (implicit signals)

What NOT to track:

  • ❌ Conversation content (privacy)
  • ❌ User queries (privacy)
  • ❌ Response quality ratings (out of scope)

Rationale: Focus on file usage patterns only, respect privacy
